# 헤이우드 그래프 스텝 L-meta-2279 작업 기록

이 브랜치는 기록 보관용입니다. `open-goat/pequalnp-proofs`에 PR로 보내지 마세요
(PR 규칙은 `lean/PEqualNP/Outside/` 아래 새 파일 하나만 허용합니다).

작성일: 2026-11-24. 결과: **미해결**. 25게이트 회로를 찾지 못했고, 없다는 증명도 못 했습니다.

## 1. 스텝이 요구하는 것

원문은 `statement.lean.txt`에 있습니다. 요약하면 다음과 같습니다.

- 그래프: 헤이우드 그래프(파노 평면의 점–선 결합 그래프). 꼭짓점 14개(점 0..6, 선 7..13),
  변 21개. 변 목록은 `rows.py`의 `E`.
- 함수: 입력 14비트 `x`에 대해 "켜진 두 꼭짓점을 잇는 변이 하나라도 있는가".
- 회로: `Monotone2`(AND/OR만, 게이트마다 입력 2개). 입력 14개 뒤에 공짜 배선 하나
  `x0 OR x1`이 15번째 입력으로 붙습니다.
- 정확해야 하는 입력: "임계 입력" 58개(변 21개 + 극대 독립집합 37개). 단조성 때문에
  이는 함수 전체를 정확히 계산하는 것과 같습니다.
- 스텝은 부정문입니다. "모든 회로는 크기 26 이상"을 거짓으로 만들려면
  **게이트 25개 이하인 회로 하나**를 Lean에서 명시적으로 제시해야 합니다.
- 책상의 설명: 이 스텝은 긍정문 L-meta-2278의 반례를 요구하며, 2278이 참이면
  반례는 없을 것으로 예상됩니다. 즉 이 스텝은 거짓일 가능성이 높습니다.

## 2. 확인된 사실

| 사실 | 확인 방법 |
|---|---|
| 완전 매칭 24개는 모두, 지우면 14-사이클 하나가 남음 | `twofactor.py` |
| 두 꼭짓점이 이웃을 2개 이상 공유하는 쌍은 0개, 정확히 1개 공유하는 쌍은 42개 | `star_circuits.py` |
| 별 분해 회로(중심 7개, 각각 `중심 AND (이웃 OR)`): 27게이트, 전체 16384 입력에서 정확 | `star_circuits.py` |
| 선 쪽 별 분해 + 공짜 OR: 26게이트, 전체 입력에서 정확 | `star_circuits.py` |

26게이트 회로는 목표(25)에 1개 모자랍니다. 선 7(이웃 0, 1, 3)만 공짜 배선을 쓸 수 있어서
절약이 1개뿐입니다.

## 3. 탐색 결과

방법: SAT 기반 정확 합성(`synth.py`)과, 별 회로 몇 개를 고정하고 나머지 게이트만
SAT로 찾는 창 탐색(`lns.py`). 솔버는 pysat의 glucose4 / cadical195.

| 탐색 | 결과 |
|---|---|
| 제한 없는 25게이트 합성 (`runall.sh`, 약 3분) | 결론 없음 |
| 제한 없는 26게이트 합성 (해가 있음이 알려진 경우, 2분·8분) | 시간 안에 못 찾음. 즉 무제한 탐색은 정보가 없음 |
| 별 6개 고정, 선 중심 7가지 (경우당 250초) | 7개 모두 UNSAT |
| 별 6개 고정, 점 중심 7가지 | 7개 모두 UNSAT |
| 별 5개 고정, 선 중심 21가지, 경우당 100초 (`logs/lns_lines_5_100s.log`) | 20개 시간 초과, 1개 미실행 |
| 별 5개 고정, 선 중심 21가지, 경우당 1250초 (`logs/lns_lines_5_1250s.log`) | 20개 시간 초과, 1개 미실행 `(9,10,11,12,13)` |

주의할 점:

- "별 6개 고정" UNSAT의 의미는 좁습니다. 표준 형태의 별 회로 6개(선 7은 2게이트,
  나머지는 3게이트)를 그대로 포함하는 25게이트 회로가 없다는 것뿐입니다.
- 별 6개 고정 실행의 로그 파일은 남기지 못했습니다. 위 결과는 실행 당시 출력에서 옮긴 것입니다.
- `lns.py`와 `synth.py`의 대칭 깨기 절(연속한 독립 게이트의 순서 고정)은 표준 기법이지만
  별도로 검증하지는 않았습니다. UNSAT 결과를 증명에 쓰려면 대칭 깨기 없이 다시 확인해야 합니다.

## 4. 다음에 해볼 것

1. **하한 쪽으로 방향 전환.** 25게이트 회로가 없다는 쪽이 더 그럴듯합니다. 그 경우 풀 수 있는
   스텝은 2279가 아니라 긍정문 L-meta-2278 계열입니다. 책상에서 해당 스텝이 열려 있는지 확인하세요.
2. **전용 정확 합성 도구.** 일반 SAT 인코딩 대신 단조 회로 전용 열거(정규형 가지치기,
   그래프 자기동형군 크기 336으로 대칭 제거)를 쓰면 25게이트 UNSAT 증명이 가능할 수 있습니다.
3. **미실행 창 하나.** `python3 lns.py lines 5 <초>`에서 `(9,10,11,12,13)`만 따로 돌리기.
4. **별 4개 이하 고정.** 자유 게이트가 13개 이상이라 현재 인코딩으로는 가망이 낮습니다.

## 5. 실행 방법

```bash
pip install python-sat
```

```bash
python3 star_circuits.py
```

```bash
python3 lns.py lines 6 250
```

`lns.py <lines|points> <고정할 별 개수> <경우당 제한 초>`. 해가 나오면 `FOUND`를 출력하고
`found_<side>_<j>.json`에 회로를 씁니다. 배선 번호는 0..13이 입력, 14가 공짜 OR,
그 뒤가 고정 게이트, 그 뒤가 찾은 게이트입니다.
